\section{Code Understanding}
As seen on the \texttt{perf} report, the interpreter spends a lot of time in \texttt{luaV\_execute}. Inside that is a large switch statement which checks against different OP\_IDs to determine what to do next. As expected, this takes a lot of time and is inefficient.
\\
\texttt{LUA\_USE\_JUMPTABLE} helps with that by enabling direct-threaded dispatch in the virtual machine using GCC/Clang computed gotos. This replaces the large switch statement, thus increasing performance.

\section{Optimization}
Applying heuristics to OP\_ADD resulted in ~1.4\% performance increase
Using all optimizations above and -fprofile-generate + -fprofile-use resulted in ~9.6\% performance increase
